# Evaluation Dataset Creation Workflow

**Status:** Ready to use

**What it does:** Teaches systematic evaluation design methodology through risk-driven test case creation. Transforms informal testing into structured evaluation that transfers to implementation phases.

**When to use:** After completing ideation workflow and initial informal testing (SVG homework)

**What you'll need:**
- Completed ideation workflow with YAML workflow artifact
- Problem definition document from ideation phase
- Experience with informal testing of your workflow

**Output:**
- Complete evaluation methodology tailored to your workflow
- 15-25 targeted test cases organized by quality risks
- CSV evaluation matrix for systematic measurement tracking
- Customized visual usage guide for ongoing evaluation

## Purpose
Addresses the challenge that past cohorts struggled with: articulating "what good means" and executing proper measurement in an actionable way that connects to design decisions.

## Expected Duration
- **Full workflow**: 2-3 hours
- **Step 1-3**: 45-60 minutes (risk identification and prioritization)
- **Step 4-6**: 60-90 minutes (test case design and artifact generation)

## Key Features
- **Risk-driven approach**: Focuses on workflow-specific quality risks rather than generic testing
- **Tactical guidance**: Step-by-step instructions for test case generation methods
- **Extensible methodology**: Evaluation approach that works across different domains and transfers to implementation
- **Context-aware**: Uses bootcamp utilities to tailor approach to your specific situation

## Deliverables
1. **Evaluation Design Report** (`your_workspace/reports/evaluation_design_report.md`)
2. **Evaluation Data Matrix** (`your_workspace/data/evaluations_data.csv`)
3. **Evaluation Usage Guide** (`your_workspace/reports/evaluation_usage_guide.svg`)

## Success Criteria
You'll know this worked when you can articulate your top quality risks, explain how your test cases target them, and have a systematic methodology for ongoing evaluation that informs design decisions.
