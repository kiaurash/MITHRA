# GSBsys Indicator System

## Architecture Overview

GSBsys uses a **multiplicative signal combination** architecture with 37 built-in technical indicators. Trading signals are generated by combining 2-5 indicators through weighted multiplication.

---

## Core Formula

```
Signal = indicator1^weight1 × indicator2^weight2 × ... × indicatorN^weightN

WHERE:
  - N = 2 to 5 (number of selected indicators)
  - Each indicator normalized to range [-100, +100]
  - Weights range from -1 to +2
  - Positive signal → bullish, Negative signal → bearish
```

## Signal Combination Logic

### Two-Stage Filter Architecture

```
Stage 1: Secondary Filter
  - Fixed rule (e.g., Close > PreviousClose)
  - OR genetically selected indicator

Stage 2: Primary Signal
  - Multiplicative combination of 2-5 indicators
  - Must exceed EntryLevel threshold

Entry Condition (Long):
  IF (SecondaryFilter > 0) AND (Signal > EntryLevel) THEN Enter Long

Entry Condition (Short):
  IF (SecondaryFilter < 0) AND (Signal < -EntryLevel) THEN Enter Short
```

### Example System

```
Indicators Selected: [TrueRange, GSB_CCI, DMIPlus]
Weights: [1.2, -0.5, 1.8]
EntryLevel: 500

Calculation:
  TrueRange_norm = 45
  GSB_CCI_norm = -30
  DMIPlus_norm = 60

  Signal = (45)^1.2 × (-30)^(-0.5) × (60)^1.8
         = 56.8 × 0.182 × 520
         = 5,378

  SecondaryFilter = Close - PreviousClose = 2.5 (positive)

  IF SecondaryFilter > 0 AND Signal > 500:
    Enter Long ✓
```

## Indicator Normalization

**Range:** All indicators normalized to **[-100, +100]**

**Normalization Modes (2 enabled):**
1. **HighestLowest** (confirmed active)
   ```
   normalized = (raw - lowest) / (highest - lowest) × 200 - 100
   ```
2. Second mode not specified in screenshots

**Normalization Length:** **100 bars**

This ensures:
- Consistent scaling across different indicator types
- Prevents one indicator from dominating the multiplicative combination
- Positive values = bullish signal
- Negative values = bearish signal

## The Multiplication Problem

**Acknowledged Flaw:**

> "2 negatives and 1 positive gives a positive result, however if 2 indicators are negative it implies a downward trend"

**Example:**
```
Indicator1 = -50 (bearish)
Indicator2 = -30 (bearish)
Indicator3 = +20 (bullish)

Signal = (-50) × (-30) × (+20) = +30,000 (BULLISH)
```

Two bearish indicators should suggest a downtrend, but multiplication produces a bullish signal.

**Why This Persists:**

The GA's fitness function filters out systems where this creates unprofitable trades. Bad signal combinations are eliminated through selection, not prevented architecturally.

**Trade-off:**
- **Pro:** Multiplication amplifies agreement (all indicators same sign → very strong signal)
- **Con:** Creates logical contradictions (even number of negatives → positive)
- **Resolution:** Fitness-based selection removes problematic combinations empirically

## Indicator Selection Process

### Stage 1: Indicator Ranking (Macro M1)

```
1. Build 20,000 systems using SINGLE indicators
2. Rank all 37 indicators by performance
3. Select top 10 performers
```

This pre-filters the indicator pool from 37 → 10 before the main GA optimization.

### Stage 2: Multi-Indicator Systems

```
1. Rebuild systems using only the top 9-12 indicators
2. GA searches combinations of 2-5 from this reduced set
3. GA optimizes:
   - Which 2-5 to combine
   - Parameters for each selected indicator
   - Weights for multiplicative combination
```

**Search Space Reduction:**

Original space: C(37, 5) = 435,897 combinations
Reduced space: C(10, 5) = 252 combinations

This greedy pre-filtering enables exhaustive exploration of the reduced space.

## Weight Optimization

**Weight Range:** **-1 to +2**

**Interpretation:**

```
weight = -1  →  Invert the indicator (bearish becomes bullish)
weight = 0   →  Remove the indicator from combination
weight = 1   →  Use indicator as-is
weight = 2   →  Square the indicator (amplify its influence)
```

**Example Effect:**
```
Indicator = 50
weight = -1  →  50^(-1) = 0.02 (severe dampening)
weight = 0   →  50^0 = 1 (neutral, no effect)
weight = 1   →  50^1 = 50 (original)
weight = 2   →  50^2 = 2500 (strong amplification)
```

Negative weights can invert indicator meaning or dampen contribution.

## Entry/Exit Parameters

### Entry Threshold
- **EntryLevel:** Minimum signal magnitude to trigger trade
- Genetically optimized
- Prevents low-confidence entries

### Stop Loss
- **Types:** Fixed, Trailing, ATR Trailing, Plock Break Even, Plock Variable
- **Value:** Genetically chosen within user-defined range
- **Units:** Currency (e.g., $800), excluding commissions/slippage
- **Best practice:** "Plock break even was very worth while using" (from testing)

### Profit Target
- **Value:** Genetically chosen (e.g., $2000)
- **Units:** Currency, excluding commissions/slippage
- **Purpose:** Prevents overfitting to outlier gains (e.g., "reduce high gains in 2008 that may cause the system to curve fit for 2008")

### Exit Modes
- Market-On-Close (MOC)
- Time-based exits
- Position-based exits (after losing trades)
- Price-based exits (compare to previous day)

## Key Insights

1. **Volatility dominates:** TrueRange, Range, and StandardDev are top performers
2. **Proprietary variants:** GSB-prefixed indicators suggest custom implementations of standard indicators
3. **Oscillator effectiveness:** Stochastic and CCI variants rank highly
4. **Multiplication architecture:** Despite acknowledged flaws, empirically validated through fitness selection
5. **Pre-filtering crucial:** Reducing 37 → 10 indicators enables exhaustive search
6. **Bounded optimization:** Stop loss and profit targets have user-defined ranges to prevent pathological GA solutions
