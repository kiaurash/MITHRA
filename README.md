# Bootcamp25 - AI Product Development Projects

This repository contains multiple AI/ML projects developed during the Bootcamp25 program.

## Projects

### 🧠 ARCHE - Reasoning Logic Tree Extraction
**Repository**: [github.com/kiaurash/ARCHE](https://github.com/kiaurash/ARCHE)

Implementation of the ARCHE (Latent Reasoning Chain Extraction) methodology for extracting structured reasoning trees from scientific papers and converting them to First-Order Logic for symbolic reasoning.

**Status**: Pipeline design complete, ready for Phase 1 implementation
**Tech Stack**: Python, LLMs (Claude/GPT-4), networkx, graphviz, Prolog/Clingo

This project has been moved to its own standalone repository to allow independent development.

---

### 📚 Mithra App - AI Learning Assistant
**Location**: [Mithra App/](Mithra%20App/)

Interactive learning application powered by AI for personalized educational experiences.

**Status**: Deployed
**Tech Stack**: Python, Gradio, Claude API

---

### 🔬 Ontology Builder
**Repository**: [github.com/kiaurash/Ontology-Builder](https://github.com/kiaurash/Ontology-Builder)

HAOL-F 2.0 framework for extracting and visualizing ontologies from scientific and experiential knowledge. Features N-ary reification, SPARQL querying, and interactive D3.js visualization.

**Status**: Complete with visualization capabilities
**Tech Stack**: Python, OWL/RDF, SPARQL, D3.js

This project has been moved to its own standalone repository to allow independent development.
